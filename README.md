# CyberLearn Library

کتابخانه فارسی و راست‌چین منابع یادگیری امنیت سایبری؛ نسخه مستقل HTML/CSS/JavaScript، بدون نیاز به نصب وابستگی.

## اجرا
1. پوشه `CyberLearn-Library` را در VS Code باز کنید.
2. فایل `index.html` را در مرورگر باز کنید. برای توسعه، می‌توانید از افزونه Live Server استفاده کنید.
3. اینترنت فقط برای فونت Vazirmatn از Google Fonts لازم است؛ در نبود اینترنت، فونت‌های جایگزین استفاده می‌شوند.

## ساختار
- `index.html`: صفحات و اسکلت رابط کاربری
- `styles.css`: طراحی واکنش‌گرا، RTL و وضعیت‌های دسترسی‌پذیری
- `resources.js`: فهرست منابع، دسته‌بندی‌ها و مسیرهای یادگیری؛ این فایل را برای مدیریت محتوا ویرایش کنید.
- `app.js`: جست‌وجو، فیلترها، نشانک‌ها، پیشرفت و ذخیره‌سازی مرورگر

## ذخیره‌سازی و محدودیت‌ها
نشانک‌ها و پیشرفت در `localStorage` همین مرورگر ذخیره می‌شوند؛ ورود کاربری یا همگام‌سازی ابری وجود ندارد. دکمه خروجی گرفتن، وضعیت را در فایل JSON ذخیره می‌کند. منابع اولیه از ناشران شناخته‌شده انتخاب شده‌اند؛ وضعیت دسترسی/قیمت ممکن است تغییر کند. فیلد `lastVerified` فقط برای پیوندهایی که هنگام آماده‌سازی بررسی شده‌اند تاریخ دارد؛ مقدار `null` یعنی تاریخ بررسی مستقل ثبت نشده است.

## ویرایش منابع
هر مورد در آرایه `RESOURCES` باید `id` یکتا، `title`، `description`، `provider`، `url`، `category`، `tags`، `level`، `language`، `cost`، `type` و `prerequisites` داشته باشد. برای حذف یا اضافه‌کردن، آرایه `RESOURCES` را در `resources.js` ویرایش کنید. اگر `id` یک منبعی را که کاربر ذخیره کرده حذف کنید، نشانک قدیمی ممکن است در فضای ذخیره‌سازی بماند، اما در رابط نمایش داده نمی‌شود.

## بررسی لینک‌ها
پیوندهای دارای تاریخ در `lastVerified` هنگام آماده‌سازی با جست‌وجوی وب و صفحات رسمی مرتبط بررسی شده‌اند. منابع دارای `null` هنوز در این نسخه تاریخ بررسی مستقل ندارند. شرایط رایگان/فریمیوم را در وب‌سایت رسمی هر ارائه‌دهنده دوباره بررسی کنید.
